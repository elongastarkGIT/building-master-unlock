MASTER UNLOCKER — Catégories vs Services
=========================================
Guide saisie Admin > Services — champs identiques au formulaire service-editor.html


RAPPEL DES CHAMPS DU FORMULAIRE
-------------------------------
  Titre          → nom affiché au client
  Slug           → identifiant URL unique (minuscules, tirets, sans espaces)
  Prix de base   → montant numérique (USD)
  Catégorie      → slug de la catégorie (Admin > Catégories)
  Groupe Service → imei | serveur | louer-outils
  Actif          → cocher = visible et commandable

PROCÉDURE DE SAISIE
-------------------
  1. Admin > Catégories → créer les 20 catégories (Partie A)
  2. Admin > Services > Nouveau service
  3. Copier chaque bloc [Sxxx] dans le formulaire :
       Titre          → champ Titre
       Slug           → champ Slug
       Prix de base   → champ Prix de base
       Catégorie      → menu déroulant
       Groupe Service → menu déroulant
       Actif          → cocher la case
  4. Enregistrer → service suivant

NOTES
-----
  • Prix à 0 = service gratuit ou prix à confirmer avant publication
  • Slug unique obligatoire — ne jamais dupliquer
  • Catégorie = slug Firestore (ex: bypass-icloud), pas le titre affiché
  • Groupe Service = menu tiroir public (IMEI / Serveur / Louer Outils)
  • Décocher Actif = service masqué sans le supprimer
